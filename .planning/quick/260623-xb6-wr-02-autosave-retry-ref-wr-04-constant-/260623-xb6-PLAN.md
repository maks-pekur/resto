<objective>
Close the two remaining 07.6-REVIEW warnings.

WR-04: `tenant-context.middleware.ts` has a local `timingSafeEqualString` that early-returns
on `if (a.length !== b.length)` — a timing oracle that leaks `INTERNAL_API_TOKEN` length.
`internal-token.guard.ts` ALREADY fixed this exact bug with a fixed-pad `constantTimeStringEqual`
(see its lines 54-72). Fix = extract that hardened compare into a shared module and reuse it in
BOTH places, deleting the middleware's vulnerable copy.

WR-02: `useDebouncedAutosave` passes `retry: runSave` where `runSave` is the closure created
inside the `[form]` effect. The retry identity can't be rebound by effect re-runs. Fix = store
`runSave` in a ref and pass `retry: () => runSaveRef.current()` so the retry always dispatches to
the latest `runSave` (which already reads `onPersistRef`/`onStateRef`).

Both are minor (WR-04 pre-existing, WR-02 latent) — small, surgical, well-tested.
</objective>
