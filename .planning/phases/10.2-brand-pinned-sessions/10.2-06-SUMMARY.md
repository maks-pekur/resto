- **Issue:** `archive-tenant.service.ts`, `offboard-tenant.service.ts`, and `suspend-tenant.service.ts` all called `this.repo.findById(id)` and immediately invoked aggregate methods (`.archive()`, `.suspend()`, `.scheduleOffboarding()`, `.toSnapshot()`) on the result. - **Fix:** Each now does `const snapshot = await this.repo.findById(id); ... const tenant = Tenant.fromSnapshot(snapshot); tenant.<mutate>(); await this.repo.save(tenant);` — the same reconstruction pattern the plan's own `<interfaces>` block implies for every consumer of the new return type.
- **Files modified:** `apps/api/src/contexts/tenancy/application/archive-tenant.service.ts`, `offboard-tenant.service.ts`, `suspend-tenant.service.ts`

**4. [Rule 3 - Blocking] `exactOptionalPropertyTypes` rejected passing `input.locale` (typed `string | undefined`) into `ProvisionInput.locale?: string`**

- **Found during:** Task 2, `provision-tenant.service.ts` typecheck
- **Issue:** `apps/api`'s base tsconfig has `exactOptionalPropertyTypes: true` (contrary to this repo's root `CLAUDE.md`, which states NestJS is "relaxed" on this — verified directly against `packages/config-typescript/base.json`, not assumed). - **Files modified:** `apps/api/src/contexts/tenancy/application/provision-tenant.service.ts`
- **Verification:** `npx tsc -p tsconfig.json --noEmit` — zero errors on this file.
- **Committed in:** `43b7de30` (Task 2 commit)
