| ------------------------------------- | -------------------------------------------------------------- |
| URL ?table= param → cart/state/DOM    | Guest-controllable query value enters the app and is displayed |
| locale cookie / URL → i18n resolution | Guest-influenced locale selection                              |

## STRIDE Threat Register

| Threat ID | Category                  | Component                          | Disposition | Mitigation Plan                                                                                                                                      |
| --------- | ------------------------- | ---------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| T-06-08   | Tampering (injection/XSS) | ?table= param + manual table entry | mitigate    | Sanitize on ingest (trim, non-empty, length cap ≤32) and render the table value only as React text children (escaped) — never as HTML/attribute sink |
| T-06-09   | Tampering                 | locale cookie / URL value          | mitigate    | detectLocale only accepts a value present in RESOURCES (en                                                                                           | ru); any other value falls through to navigator/default — no arbitrary string is used |
| T-06-10   | DoS                       | oversized table input              | accept      | Length cap on entry bounds the stored value; client-only impact, no server amplification                                                             |

</threat_model>
