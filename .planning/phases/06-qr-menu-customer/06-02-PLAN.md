<objective>
Expose `isStopListed: boolean` through the full `/v1/menu` chain so stop-listed items render as visibly disabled (QRM-09) instead of disappearing. Purpose: QRM-09 is unimplementable on the frontend until the API ships the flag. This is the critical-path backend dependency for the qr-menu stop-list UI (Wave 4). Tenant isolation (ScopedTx/RLS) MUST remain intact.
Output: `/v1/menu` returns all items with `isStopListed`; api-client + OpenAPI regenerated; website passes the flag.
</objective>
