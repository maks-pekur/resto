## What Was Built

**Task 1 — Guard flip (D-08 / D-10 / D-11):**

- Created `brand-neutral.decorator.ts` exporting `BRAND_NEUTRAL_KEY = 'identity:brand-neutral'` and `@BrandNeutral()` decorator, re-exported from `shared/auth/index.ts`.
- Rewrote `BrandScopeGuard` to be default-on (reads `BRAND_NEUTRAL_KEY`, not `REQUIRE_BRAND_KEY`). Removed the dangling `REQUIRE_BRAND_KEY` import (was an ESLint `no-unused-vars` failure waiting to happen).
- Flipped L77 `if (scope === null) return true` to throw `ForbiddenException({ code: 'brand.access_denied' })` (D-08 default-deny for non-owners).
- Owner bypass (`baseRole === 'owner'`) runs before pin check AND scope lookup — a fresh owner with zero scope rows is never locked out.
- Added D-10 pin reconciliation for non-owners: `activeBrandId === null` OR `activeBrandId !== alsBrandId` → `NotFoundException()` (existence-hiding 404). Closes the null-pin bypass the security review flagged.

**Task 2 — Role-aware semantics + @BrandNeutral enumeration (D-11):**

- Updated `member-brand-scope-reader.port.ts` doc: `null` = "no scope rows" (fact, not policy — the allow/deny decision is the role-aware caller's).
- Made `canViewAllBrands` role-aware in `list-my-brands.service.ts`: `isOwner && scopeRows === null`. Non-owner with no scope rows gets `false`.
- Updated `getBrands` in `me-brands.controller.ts` to pass `isOwner: operator.baseRole === 'owner'`.
- Applied `@BrandNeutral()` to 13 controllers: `PublicMenuController`, `OrdersController`, `CheckoutController`, `SignUpController`, `BrandOAuthCallbackController`, `StripeWebhookController`, `HealthController`, `InternalBootstrapController`, `InternalTenantsController`, `MeController`, `MeBrandsController`, `SetActiveBrandController`, `TenantsController`.
- Left 4 controllers brand-scoped (no annotation): `CatalogController`, `RefundsController`, `BrandOnboardingController`, `StripeOnboardingController` (D-14 payout audit).
- Created `docs/security/08.2-brand-neutral-controller-audit.md`: full classification table for all 15 NestJS controllers + BA-managed `/api/auth/*` row.

**Task 3 — Test matrix (inverted + extended):**

- Inverted the stale "passes for non-owner when scope is empty (default-allow)" test to assert `403 brand.access_denied` (default-deny).
- Added 8 new test cases: owner-null-scope passes, owner-null-pin passes, owner-pin-mismatch passes, non-owner-null-pin → NotFoundException, non-owner-pin-mismatch → NotFoundException, anonymous-without-@BrandNeutral → 403 operator_required, @BrandNeutral → pass, non-owner-in-scope-with-pin-match → pass.
- Updated `list-my-brands.service.spec.ts` to pass `isOwner` (required by the new interface).
- Full suite: 476/476 tests passing.
