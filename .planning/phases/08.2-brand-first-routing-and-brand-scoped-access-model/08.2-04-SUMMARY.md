# Phase 08.2 Plan 04: Brand-First Routing Summary

**Flattened admin SPA from /dashboard/{brand}/... to /{brand}/..., fixed Stripe Connect return URL money-path regression, and replaced broken organization.setActive with server-pin POST /v1/me/set-active-brand.**

- **Completed:** 2026-07-02

## Accomplishments

- Flattened the TanStack route tree: removed `dashboardLayoutRoute` indirection; `$brandSlug` is now a direct child of `protectedLayoutRoute`; every admin page lives under `/{brand}/...`
- Fixed the Stripe Connect return URL regression (`/dashboard/${slug}/payouts` → `/${slug}/payouts`) — the single highest-impact money-path line; a miss silently 404s Stripe Connect Standard OAuth return for every new brand
- Replaced the latent brand-switcher bug (`organization.setActive({ organizationId: brand.id })` passing a brand UUID as an org ID) with `apiFetch POST /v1/me/set-active-brand`
- Added `dashboard-redirect.$.tsx` catch-all shim so legacy `/dashboard/{brand}/*` bookmarks and stale Stripe/admin links redirect transparently to `/{brand}/*`
- Wired `/` index to redirect to the active brand's slug (no brand-picker screen, D-04)
- Moved `settings` and `team` under `/{brand}/...` URLs while keeping their data tenant-scoped (D-05)
- Human-verify checkpoint (Task 3) approved by founder: brand-first routing, switcher, deep links, legacy redirect, and Stripe return URL all confirmed working

## Decisions Made

- **Endpoint path correction:** The plan text references `/v1/identity/me/set-active-brand` but the API has no `/identity/` URL segment. The correct path is `/v1/me/set-active-brand`, matching what Plan 03 actually implemented. The brand-switcher uses the correct path.
- **Shim lifecycle:** `dashboard-redirect.$.tsx` is intentionally short-lived. Remove it in a future cleanup phase once legacy bookmarks and Stripe OAuth links (which may have cached the old URL) have aged out. The no-comments policy means this note lives here, not in the source file.
- **D-05 boundary held:** settings and team data queries remain tenant-scoped; only their URL prefix changed. No per-brand data model introduced in this plan.
- **`dashboard` stays reserved:** Plan 01 reserved `dashboard` as a slug, so the `/dashboard/*` catch-all can never shadow a real brand — the redirect shim is safe.

- **Fix:** Brand-switcher calls `/v1/me/set-active-brand` (correct path). This is a plan text error, not a code error.
- **Committed in:** b0d6a99 (Task 2 commit)
