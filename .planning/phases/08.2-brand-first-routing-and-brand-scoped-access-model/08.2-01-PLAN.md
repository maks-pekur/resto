<objective>
Extend the reserved-slug contract so brand slugs can never shadow an admin root route once
the `/dashboard` prefix is dropped (D-06), add a drift test that fails when a new root route is
added without reserving it, and ship a one-shot collision detector for existing brand slugs
(D-07). This plan is the shared dependency that makes the Wave-2 SPA route move (Plan 04) safe.

Purpose: D-03's clean `/{brand}` form makes the first URL path segment a brand slug. Without
reserved-word coverage of the auth/onboarding root routes, a brand named `login` would shadow
the login route. D-06 mandates route-derived reservation; D-07 mandates a pre-ship collision
check. This plan stays entirely in `@resto/domain` + scripts/tests — no behavior change to the
running API beyond a stricter slug refine.

Output: 4 new reserved words, an `ADMIN_ROOT_ROUTE_SEGMENTS` exported contract, a Vitest drift
spec, a unit spec proving the new words are rejected, and a collision-check script.

Scope guard (D-01/D-02): brand-level only. No `locations`, no `dynamicAccessControl`, no
custom-role primitives touched here.
</objective>
