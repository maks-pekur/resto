## Trust Boundaries

| Boundary                              | Description                                                                                                                     |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| browser URL → SPA router              | a user edits the URL to a brand slug they may not be scoped to (server guards are the real boundary; SPA gracefully falls back) |
| Stripe OAuth return → admin URL       | external redirect must land on a valid, brand-correct path                                                                      |
| legacy /dashboard/\* URL → SPA router | old bookmarks/links must forward to the flat path, never silently 404 or loop                                                   |
| brand-switcher → set-active-brand API | switch must go through the server pin, not a client-set org/brand                                                               |
