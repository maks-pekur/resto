<objective>
Put the table on the operator's order card: a dine-in order from a scanned table shows its zone and number, a legacy free-text order still shows its text, and a pickup order shows nothing.

Purpose: on a busy Friday the operator triages from cards, and today they cannot see the table without opening a detail sheet per order. Note that TBL-12's own "Current" line in the SPEC is wrong — `order-card.tsx` contains no reference to any table field at all, and the only render site in the admin is `order-detail-sheet.tsx:266-268`. This is an addition to the card, not an edit to an existing block; size it accordingly and do not go looking for code that is not there.
Output: two columns on the feed DTO, a table line on the card, and the fallback rule written down where the next contributor will read it.
</objective>
