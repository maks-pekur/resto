Deliver embedded Express onboarding per brand (PAY-14) and the resumable method-choice surface (PAY-17, Express side). <threat_model>

## Trust Boundaries

| Boundary                                       | Description                                                             |
| ---------------------------------------------- | ----------------------------------------------------------------------- |
| Admin SPA (browser) → account-session endpoint | Browser requests a client_secret minted with the server-only secret key |
| Operator session → per-brand onboarding        | An operator must be scoped to the brand they onboard (RBAC)             |

## STRIDE Threat Register

| Threat ID    | Category               | Component                                                                  | Disposition | Mitigation Plan                                                                                                                                                                                                                                         |
| ------------ | ---------------------- | -------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-08.1-04-01 | Information Disclosure | Publishable vs secret key boundary                                         | mitigate    | Only `VITE_STRIPE_PUBLISHABLE_KEY` (public) ships in the SPA bundle; the Account Session `client_secret` is minted server-side from `STRIPE_SECRET_KEY` (never in the browser).                                                                         |
| T-08.1-04-02 | Elevation of Privilege | Cross-brand onboarding (operator onboards a brand they don't own)          | mitigate    | `account-session`/`account-link`/`status` endpoints carry `@RequireActiveTenant()` + `@Permissions({ tenant: ['transfer'] })` + `@RequireBrand()`; the brand is resolved from `(tenantId, slug)` under RLS + ScopedTx, never from a client-supplied id. |
| T-08.1-04-03 | Spoofing               | `onExit` mistaken for completion                                           | mitigate    | Completion authority is the `account.updated` webhook (Plan 03); `onExit` only refetches status; the per-brand `canAcceptPayments()` gate enforces at checkout (RESEARCH Pitfall 3).                                                                    |
| T-08.1-04-04 | Tampering              | Server fetch without timeout (admin reads)                                 | mitigate    | `apiFetch` already applies `AbortSignal.timeout` (apps/CLAUDE.md); the fetchClientSecret callback uses the same client.                                                                                                                                 |
| T-08.1-04-SC | Tampering              | npm installs `@stripe/connect-js` + `@stripe/react-connect-js` ([ASSUMED]) | mitigate    | Blocking human-verify checkpoint (Task 0) verifies both on npmjs.com before install; slopcheck was unavailable so the install is gated, not auto-approved.                                                                                              |

</threat_model>
