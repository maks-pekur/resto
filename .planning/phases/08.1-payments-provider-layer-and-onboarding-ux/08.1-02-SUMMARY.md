## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] oauth.token return type mismatch**

- **Found during:** Task 2, tsc run
- **Issue:** `StripeClientLike.oauth.token` declared `{ stripe_user_id: string | null }` (required) but the real `stripe.oauth.token` returns `OAuthToken` where `stripe_user_id` is optional (`string | null | undefined`)
- **Fix:** Changed to `{ stripe_user_id?: string | null }` in `StripeClientLike`; added null/empty guard in `exchangeOAuthCode` that throws if absent
- **Files modified:** `stripe-provider.adapter.ts`
- **Commit:** 681d01e

**2. [Rule 1 - Bug] async stubs trigger @typescript-eslint/require-await**

- **Found during:** Task 3 lint-staged pre-commit
- **Issue:** `StubProviderAdapter` methods declared `async` but had no `await` expressions — ESLint `require-await` rule rejected them
- **Fix:** Converted all stub async methods to synchronous methods returning `Promise.resolve(...)`, which satisfies the port contract without triggering the rule
- **Files modified:** `stub-provider.adapter.ts`
- **Commit:** 2135a36

**3. [Expected pre-existing violation] handle-stripe-event.service.ts imports Stripe**

- **Status:** Not fixed in this plan — by design
- **Explanation:** `handle-stripe-event.service.ts` has `import type Stripe from 'stripe'` in the payments application layer, which the new PAY-16 ESLint rule correctly flags. This is the exact file Plan 03 will repoint to use `PaymentProviderPort.verifyWebhookSignature`. The architecture test is functioning correctly. The plan's verify command (`eslint src/contexts/payments/application --max-warnings 0`) will pass clean after Plan 03.
- **Action:** Documented; not blocked. Plan 03 resolves it.

**4. [TDD gate] RED commit skipped due to pre-commit tsc hook**

- **Status:** Merged RED + GREEN into single commit (2135a36)
- **Explanation:** The project's pre-commit hook runs `tsc --noEmit` which rejects a spec importing a non-existent module. A pure RED commit (spec only, no implementation) cannot pass the hook. The spec was written first and proved the RED failure via `npx vitest run` before the implementation was added. TDD intent preserved; commit structure merged.
