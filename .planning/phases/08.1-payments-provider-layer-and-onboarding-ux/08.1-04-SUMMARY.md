## What Was Built

**Task 1 — Packages + env key:**

- `@stripe/connect-js@3.4.6` and `@stripe/react-connect-js@3.4.4` added to `apps/admin` dependencies.
- `VITE_STRIPE_PUBLISHABLE_KEY` exported from `apps/admin/src/env.ts` via `getEnv` — fails loud in PROD when unset, returns empty string in DEV (no placeholder value hardcoded).

**Task 2 — Per-brand onboarding service + controller:**

- `StartBrandOnboardingService` (`@Injectable()`) injecting `BRAND_REPOSITORY`, `PAYMENT_PROVIDER_PORT`, `ENV_TOKEN`.
- `ensureBrandAccount(slug)`: finds brand via `findByTenantAndSlug(TenantId.parse(rawTenantId), BrandSlug.parse(slug))`; if no Stripe account yet, calls `provider.ensureOnboardingAccount({ accountType: 'express' })`, calls `brand.linkPaymentAccount(accountId, 'express')`, persists via `brandRepo.updatePaymentConnection(brand)`.
- `createEmbeddedSession(slug)`: ensures account, calls `provider.createOnboardingSession({ accountId })`, returns `{ clientSecret }`.
- `createHostedLink(slug)`: ensures account, calls `provider.createOnboardingLink(...)` with env return/refresh URLs, returns `{ onboardingUrl }`.
- `getStatus(slug)`: reads snapshot, returns `{ accountType, onboardingStatus, chargesEnabled, payoutsEnabled, canAcceptPayments, requirementsDue }`.
- `BrandOnboardingController` at `v1/tenancy/brands/:slug/onboarding` with `@Post('account-session')`, `@Post('account-link')`, `@Get('status')` — each guarded with `@RequireActiveTenant()` + `@Permissions({ tenant: ['transfer'] })` (status: `['read']`) + `@RequireBrand()`.
- Both registered in `TenancyModule`.

**Task 3 — Admin payouts page:**

- `apps/admin/src/lib/brand-payments-api.ts`: typed helpers `getBrandPaymentStatus`, `startBrandEmbeddedSession`, `startBrandHostedLink` calling per-brand onboarding endpoints via `apiFetch` with `brandSlug`.
- `brands.$slug.payouts.tsx` fully rewritten: method-choice block ("Create new (Express)" primary CTA + "Connect existing (Standard) — coming soon" placeholder), embedded `ConnectComponentsProvider` + `ConnectAccountOnboarding` when `connectInstance` is non-null, hosted-link fallback when `VITE_STRIPE_PUBLISHABLE_KEY` absent. Resumability: state derived from `getBrandPaymentStatus` (accountType + onboardingStatus). `onExit` refetches status only — completion authoritative via `account.updated` webhook.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] TenantId branded type required for findByTenantAndSlug**

- **Found during:** Task 2 typecheck
- **Issue:** `requireTenantContext()` returns raw `string` for `tenantId`, but `BrandRepository.findByTenantAndSlug` requires `TenantId` branded type.
- **Fix:** Added `TenantId.parse(rawTenantId)` parse at call site in both `ensureBrandAccount` and `getStatus`.
- **Files modified:** start-brand-onboarding.service.ts

**2. [Rule 1 - Bug] exactOptionalPropertyTypes: defaultCurrency undefined not assignable**

- **Found during:** Task 2 typecheck
- **Issue:** `CreateOnboardingAccountInput.defaultCurrency?: string` with `exactOptionalPropertyTypes: true` rejects `string | undefined`; passing `snapshot.defaultCurrency ?? undefined` fails.
- **Fix:** Used conditional spread `...(snapshot.defaultCurrency !== null ? { defaultCurrency: snapshot.defaultCurrency } : {})`.
- **Files modified:** start-brand-onboarding.service.ts

**3. [Rule 1 - Bug] StripeConnectInstance type incompatibility with local stub interface**

- **Found during:** Task 3 typecheck
- **Issue:** Local `ConnectInstance` interface didn't match `StripeConnectInstance` from `@stripe/connect-js` (strict `create` method signature).
- **Fix:** Imported `StripeConnectInstance` from `@stripe/connect-js` and used it for prop types.
- **Files modified:** brands.$slug.payouts.tsx

**4. [Rule 1 - Bug] ESLint no-confusing-void-expression + no-non-null-assertion**

- **Found during:** Task 3 pre-commit hook
- **Issue:** Arrow shorthand `() => void statusQuery.refetch()` and non-null assertion `fetchClientSecretRef.current!` flagged.
- **Fix:** Used `useRef` with direct initialization (removing `null` initial value eliminates non-null assertion); wrapped void expressions in braces via `eslint --fix`.
- **Files modified:** brands.$slug.payouts.tsx

## Threat Surface Scan

No new network endpoints or auth paths beyond what the plan's `<threat_model>` covers:

- `POST account-session` — server mints client_secret from STRIPE_SECRET_KEY (never browser-visible). Guarded by `@RequireActiveTenant + @Permissions(['transfer']) + @RequireBrand`.
- `POST account-link` — same guards, hosted fallback. No publishable key involved.
- `GET status` — read-only, guarded by `@Permissions(['read']) + @RequireBrand`.
- `VITE_STRIPE_PUBLISHABLE_KEY` baked into SPA bundle (public by design; not a secret).
