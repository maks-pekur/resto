## Trust Boundaries

| Boundary                                  | Description                                                                |
| ----------------------------------------- | -------------------------------------------------------------------------- |
| Stripe OAuth redirect → callback endpoint | An unauthenticated, externally-triggered request carrying `code` + `state` |
| Operator → brand account linkage          | The state binds the flow to a specific brand the operator started          |

## STRIDE Threat Register

| Threat ID    | Category               | Component                                                     | Disposition | Mitigation Plan                                                                                                                                                                                                 |
| ------------ | ---------------------- | ------------------------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-08.1-05-01 | Tampering/Spoofing     | OAuth CSRF (attacker links their account to a victim's brand) | mitigate    | Signed, single-use `state` carrying `brandId` (HMAC + nonce), verified before any side effect; nonce bound to the operator session cookie set at `oauth/start`; expired/tampered state → 400.                   |
| T-08.1-05-02 | Tampering              | Open redirect on the callback return URL                      | mitigate    | Post-callback redirect target is constructed from `ADMIN_WEB_URL` + the brand slug and refined against protocol-relative URLs (`!/^\/[\\/]/`); no client-supplied return URL is honored (apps/CLAUDE.md CR-01). |
| T-08.1-05-03 | Information Disclosure | Storing the deprecated OAuth `access_token`                   | mitigate    | `exchangeOAuthCode` returns only `stripe_user_id`; the service persists only the account id; no secret-key/access-token handling (PAY-15, RESEARCH State of the Art).                                           |
| T-08.1-05-04 | Tampering              | Replayed OAuth `code`                                         | mitigate    | Stripe `code` is single-use + 5-min TTL and is exchanged server-side immediately; the `state` nonce is also single-use.                                                                                         |
| T-08.1-05-05 | Elevation of Privilege | Cross-brand link via callback                                 | mitigate    | The brand is taken from the signed `state`, not a client param; `oauth/start` is brand-RBAC-guarded so only a scoped operator can mint a valid state.                                                           |
| T-08.1-05-SC | Tampering              | npm/pip/cargo installs                                        | mitigate    | No new package installs in this plan (server `stripe` already present; browser packages installed + gated in Plan 04).                                                                                          |

</threat_model>
