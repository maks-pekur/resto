<objective>
Repoint every tenant-keyed Stripe resolution to the **order's brand** (D-07) and switch the payments services + webhook controller onto `PaymentProviderPort` (PAY-16): checkout resolves `brand.stripeAccountId` + `brand.defaultCurrency` from `order.brandId`; the capability predicate (`canAcceptPayments`) gates checkout at the brand; the webhook handlers resolve/update the **brand** by Stripe account id; the webhook controller delegates signature verification to `verifyWebhookSignature`; and the module wiring binds `PAYMENT_PROVIDER_PORT → StripeProviderAdapter`. Remove the old `STRIPE_CONNECT_PORT` token + tenancy Stripe adapter once nothing references them.

Purpose: Closes the per-brand reshape end-to-end and completes the provider seam consumption. This is where the locked money model (direct charges, `application_fee` = config default 0) is preserved while the account/currency source moves tenant → brand (RESEARCH Pitfall 4).
Output: Per-brand checkout/webhook/refund, port-based DI, and removal of the dead tenant Stripe port + adapter.
</objective>
