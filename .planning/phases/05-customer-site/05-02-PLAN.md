## Trust Boundaries

| Boundary                        | Description                                     |
| ------------------------------- | ----------------------------------------------- |
| Browser → Next.js middleware    | Untrusted host header + query params cross here |
| Next.js server → API `/v1/menu` | Tenant context forwarded via x-tenant-slug      |

## STRIDE Threat Register

| Threat ID | Category               | Component                              | Disposition | Mitigation Plan                                                                                                                                                                                                                                                                                                    |
| --------- | ---------------------- | -------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| T-05-02-S | Spoofing               | middleware `?tenant=` dev fallback     | mitigate    | Guard the query-param slug path with `NODE_ENV !== 'production'` (Pitfall 6); a RED-first unit test asserts a prod `?tenant=evil` yields no forwarded `x-tenant-slug` (Task 1 hard invariant); in prod the slug derives only from the host the platform routes — a browser cannot forge another tenant's subdomain |
| T-05-02-T | Tampering              | client-supplied `x-tenant-slug` header | mitigate    | Middleware SETS `x-tenant-slug` on the forwarded request from the host/dev-query; it never trusts an inbound `x-tenant-slug` from the browser. The API additionally rejects header overrides outside dev / internal routes (verified in tenant-context.middleware.ts)                                              |
| T-05-02-I | Information Disclosure | INTERNAL_API_TOKEN                     | mitigate    | Env schema deliberately omits the token; website calls only `@Public()` `/v1/menu` — no server-only secret enters the website bundle                                                                                                                                                                               |
| T-05-02-D | Denial of Service      | host-header / open-redirect on locale  | mitigate    | Locale resolution only writes a cookie from an allowlisted LOCALES set (`isLocale`); never reflects raw header/host into a redirect target                                                                                                                                                                         |
| T-05-02-R | Repudiation            | tenant suspension visibility (TEN-02)  | accept      | 403 from `/v1/menu` is surfaced as the "temporarily unavailable" state in 05-03; layout degrades silently to default theme — acceptable, no audit surface needed on the public site                                                                                                                                |
