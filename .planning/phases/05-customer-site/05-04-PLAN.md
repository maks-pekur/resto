| Threat ID | Category               | Component                                | Disposition | Mitigation Plan                                                                                                                                                                                                                                                 |
| --------- | ---------------------- | ---------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-05-04-T | Tampering              | client-side cart prices (sessionStorage) | mitigate    | Snapshotted prices are display-only in Phase 5; Phase 7 MUST recompute authoritative totals server-side from the published menu at order creation (ORD-05 domain calc) — never trust the client cart's prices. Documented as a Phase 7 invariant in the SUMMARY |
| T-05-04-I | Information Disclosure | localStorage vs sessionStorage           | mitigate    | Use sessionStorage so a guest's cart does not leak across sessions/visits (RESEARCH Anti-Pattern); cleared on tab close                                                                                                                                         |
| T-05-04-D | Denial of Service      | hydration mismatch crash on cart badge   | mitigate    | `useHasHydrated()` gate + `suppressHydrationWarning` on the badge (Pitfall 2)                                                                                                                                                                                   |
