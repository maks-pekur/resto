# Phase 08.3 Plan 04: Owner-Facing Admin Roles UI

The front-end for the server-side role model: an owner-gated Roles list, a presets-first role
editor driven by the permission catalog (NON_DELEGATABLE toggles hidden), and the Team-page
active-member assignment surface. The UI enforces no authority of its own — every server
rejection is surfaced with the exact UI-SPEC copy via `friendlyRoleError`.
