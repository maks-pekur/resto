## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] ArchiveRoleService removed AUTH_TOKEN injection**

- **Found during:** Task 2 implementation
- **Issue:** The plan listed `AUTH_TOKEN` as an injection for archive-role.service, but archive does the occupied-check + soft-UPDATE entirely via `AuthDrizzle` (no BA API call needed since soft-delete is a direct SQL UPDATE). Injecting AUTH_TOKEN without using it creates dead code.
- **Fix:** Removed AUTH_TOKEN injection; ArchiveRoleService only injects AUTH_DRIZZLE_TOKEN + IDENTITY_EVENT_EMITTER.
- **Files modified:** archive-role.service.ts, role-services.spec.ts

**2. [Rule 1 - Bug] ArchiveRoleService uses two-pass member count for CSV accuracy**

- **Found during:** Task 2 implementation
- **Issue:** A single SQL LIKE `%slug%` query would false-positive on slug substrings (e.g., 'cashier' would match a member with role 'cashier-vip'). The plan called for a member-count query without specifying the exact mechanism.
- **Fix:** Single SQL SELECT of all members for the org, then in-process CSV split + exact slug match. Cleaner than two DB queries.
- **Files modified:** archive-role.service.ts

**3. [Rule 3 - Blocking] TDD RED+GREEN co-committed (typecheck hook)**

- **Found during:** Task 2 RED commit attempt
- **Issue:** Pre-commit hook runs `tsc --noEmit`; a RED-only test file with imports of non-existent modules fails typecheck and blocks the commit.
- **Fix:** Implemented services immediately after writing tests, then committed RED+GREEN together in one commit per the established CLAUDE.md pattern (04b-01 decision: "TDD RED+GREEN co-committed when pre-commit typecheck refuses RED-only").
- **Files modified:** all Task 2 files

**4. [Rule 3 - Blocking] `@resto/domain` subpath import not available**

- **Found during:** Task 2 implementation
- **Issue:** `import { containsNonDelegatable } from '@resto/domain/rbac/non-delegatable'` fails — domain package only exports `.` entry point. containsNonDelegatable is already re-exported via `export * from './rbac'` in the domain index.
- **Fix:** Changed to `import { containsNonDelegatable } from '@resto/domain'`.
- **Files modified:** create-role.service.ts, update-role.service.ts

**5. [Rule 3 - Blocking] ESLint no-unsafe-argument blocks `any` mock cast**

- **Found during:** Task 2 commit attempt
- **Issue:** Test mocks typed as `any` caused `@typescript-eslint/no-unsafe-argument` ESLint errors at every service constructor call site.
- **Fix:** Import `Auth` type and use `({ api: roleApi }) as unknown as Auth` — the same pattern as `bootstrap-owner.service.spec.ts` uses `as never`.
- **Files modified:** role-services.spec.ts
