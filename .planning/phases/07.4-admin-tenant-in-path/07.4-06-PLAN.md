<objective>
Collapse the server-side environment onto the single-apex scheme: the operator cookie becomes
host-only, the per-tenant admin origin disappears, and `ADMIN_WEB_URL` starts carrying a path
without breaking the one consumer that cannot accept one.

Purpose: `AUTH_COOKIE_DOMAIN` is currently **required** outside dev/test, and under this scheme every
legal value is wrong (07.4-CONTEXT D-05). `ADMIN_WEB_ORIGIN_WILDCARD` describes per-tenant admin
origins that no longer exist. And `ADMIN_WEB_URL` becomes `https://<apex>/admin` while Better Auth
compares trusted origins as `pattern === getOrigin(url)` — read from
`better-auth@1.6.30 dist/auth/trusted-origins.mjs` (research M-12) — so a value carrying a path can
**never** match and every mutating request from the admin would be rejected as an untrusted origin.

Output: a schema that permits the correct configuration, a trusted-origin computation that survives
the path, and one module owning every admin deep link the API emits.
</objective>
