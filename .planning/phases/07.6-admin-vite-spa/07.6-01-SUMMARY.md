# Phase 7.6 Plan 01: Relocate catalog GET reads to operator surface — Summary

**One-liner:** 7 catalog GET reads relocated from `InternalCatalogController` (internal token) to `CatalogController` (operator session + `@Permissions({ menu: ['read'] })`), closing HIGH-7 by removing the internal token path for all admin catalog reads.

## What Was Done

**Task 1:** Added imports for `Get`, `Query`, all 7 response DTOs (`CategoryListResponseDto`, `ItemListResponseDto`, `ItemDetailResponseDto`, `ModifierGroupListResponseDto`, `ModifierGroupDetailResponseDto`, `StopListResponseDto`, `DraftDiffResponseDto`), `ItemStatusFilter`, and the 7 read services. Injected all 7 services into the `CatalogController` constructor. Added 7 GET handlers with handler bodies copied verbatim from `InternalCatalogController`. Each handler carries `@Permissions({ menu: ['read'] })` (total: 7 occurrences). The 6 brand-scoped reads also carry `@RequireBrand()`. `draft-diff` is tenant-only (no `@RequireBrand()`), matching its existing service behavior. `@ApiUnauthorizedResponse` → `@ApiForbiddenResponse` on all new handlers.

**Task 2:** Deleted `internal-catalog.controller.ts`. Removed its import and reference from `catalog.module.ts`, leaving `controllers: [PublicMenuController, CatalogController]`. All 7 application services remain as module providers (already registered; now consumed only by `CatalogController`). No non-admin, non-generated caller of `internal/v1/catalog` existed outside `apps/admin` (retiring Next.js app) and `packages/api-client/src/generated/api.ts` (generated from OpenAPI — will be regenerated when `openapi.yaml` is updated in a later plan).

**Task 3:** Rewrote `catalog-reads.e2e.spec.ts` to use operator session + `x-brand-slug` headers on `v1/catalog` instead of internal token on `internal/v1/catalog`. Removed the `internal` header set from `AuthedTenant`. Added three new auth-gate assertions:

- Unauthenticated `GET /v1/catalog/categories` returns 401 or 403 (not 200)
- Operator with out-of-scope `x-brand-slug` (from tenant B) gets 403 on a brand-scoped read
- `GET /v1/catalog/draft-diff` succeeds with tenant headers only (no brand header required)
