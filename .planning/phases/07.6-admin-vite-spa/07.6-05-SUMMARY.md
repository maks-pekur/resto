# Phase 07.6 Plan 05: Catalog Admin Surface Port — Summary

TanStack Query catalog layer + full menu editor/list/publish surfaces ported from Next.js RSC + server-actions to the React+Vite SPA with operator `v1/catalog` endpoints.

## What Was Built

**Task 1 — Query layer + lib** (`1c8aaf3`)
`apps/admin/src/lib/queries/catalog.ts` owns all catalog reads and mutations:

- Query factories: `categoriesQuery`, `itemsQuery`, `itemQuery`, `modifierGroupsQuery`, `modifierGroupQuery`, `stopListQuery`, `draftDiffQuery` — each with `['catalog', resource, brandSlug]` key shape and `staleTime: 30_000` (stable) / `10_000` (draft-diff)
- Mutation functions: `upsertCategory`, `reorderCategories`, `archiveCategory`, `upsertItem`, `archiveItem`, `upsertItemSize`, `upsertItemModifierGroups`, `toggleStopList`, `resetStopList`, `upsertModifierGroup`, `upsertModifierOption`, `getPhotoUploadUrl`, `schedulePublish`, `cancelPublish`
- All calls go through `apiFetch` with `brandSlug` → `x-brand-slug` header
- Supporting lib: `types.ts` (Status, SaveState, DraftDiffEntry), `zod-schemas.ts` (form schemas + `coerceStatusFilter`), `use-auto-save.ts` (debounced auto-save hook), `localized.ts` (`fromLocalizedText`), `format-age.ts`, `toast-helpers.ts`
- Behavior-critical components: `StickyPublishBar`, `PublishCountdownToast`, `StatusBadge`, `CategorySelect`, `AutoSaveIndicator`

**Task 2 — Editor/table/form/widget components** (`a9bd59e`, `3dbd360`)
Full set of `apps/admin/src/components/menu/` SPA components:

- `ItemsTable` — optimistic stop-list toggle, archive dialog, pagination, `data-testid="item-row-{id}"`
- `CategoriesTable` — DnD reorder (dnd-kit, 600ms hold-to-nest), inline edit Sheet
- `ItemDetailForm` + `ItemEditorShell` — full item editor with auto-save, photo upload, sizes, modifier group assignment
- `CategoryForm`, `ModifierGroupFormComponent`, `ModifierOptionsList`, `GroupEditorShell`
- `ItemsFilterBar` — debounced search (300ms), CategorySelect + Status filter
- `PhotoUpload` — presigned URL via `getPhotoUploadUrl`, PUT with `AbortSignal.timeout(60_000)`, drag-drop
- `StopListTable`, `TodaysWidget`, `TodaysResetButton`, `BjuRow`, `ItemAside`, `ItemSizesCard`, `ItemModifierGroupsCard`

**Task 3 — Menu route subtree + dashboard rewire** (`55f48b8`)

- `_layout.tsx` — queries `draftDiffQuery`, maps `DraftDiffEntryApi.name` (Record|string) to string for `StickyPublishBar`
- `categories.tsx`, `items.tsx`, `items.$id.tsx`, `stop-list.tsx`, `modifier-groups.tsx`, `modifier-groups.$id.tsx`
- `items.tsx` uses `validateSearch: z.object({ page, status, categoryId, q })` with `.catch()` defaults
- `items.$id.tsx` and `modifier-groups.$id.tsx` use `useQuery({ enabled: !isNew })` (not `useSuspenseQuery` — no `enabled` support)
- `dashboard/index.tsx` rewired: real `stopListQuery` replaces placeholder; `TodaysWidget count={stopListResult?.data?.items.length ?? 0}`
- `main.tsx` wired: all 6 child routes added under `menuRouteTree`

**Task 4 — Vitest spec** (`450a524`)
`test/catalog-spa.spec.tsx` — 19 tests across 4 suites:

- Query key factories (8 assertions — shape, staleTime ordering, loader prefetch combinations)
- `ItemsTable` list render (4 — rows present, empty state, back button page 1/2)
- `StickyPublishBar` publish-toast id (3 — no-render when 0, `toast.custom` with `id: 'publish-countdown'`, `toast.error` on failure)
- Dashboard widget (3 — count badge, `stopListQuery` key prefix, count from items.length)

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `CategorySelectOption.name` is `string`, not `Record<string,string>`**

- Found during: Task 2 (components)
- Issue: `CategorySelect` expects `name: string` but `CategoryListItemApi.name` is `Record<string,string>`
- Fix: Applied `fromLocalizedText(c.name)` at every call site (`category-form.tsx`, `item-detail-form.tsx`, `items.tsx`)
- Files modified: 3 component/route files

**2. [Rule 1 - Bug] `fromLocalizedText` applied to `ModifierGroupApi.name` which is already `string`**

- Found during: Task 2 (`group-editor-shell.tsx`)
- Fix: Removed `fromLocalizedText` call; `g.name` used directly; import removed
- Files modified: `group-editor-shell.tsx`

**3. [Rule 1 - Bug] `no-unsafe-call` ESLint on `(navigate as any)(...)` call line**

- Found during: Tasks 2–3 across multiple components
- Fix: Wrapped with block-level `/* eslint-disable */` / `/* eslint-enable */` comments (not line-level `// eslint-disable-next-line` which only suppresses the next line)
- Files modified: `items-table.tsx`, `item-modifier-groups-card.tsx`, `item-detail-form.tsx`, `modifier-group-form.tsx`, `modifier-groups.tsx`, `items.tsx`

**4. [Rule 1 - Bug] `useSuspenseQuery` does not accept `enabled` option**

- Found during: Task 3 (`items.$id.tsx`, `modifier-groups.$id.tsx`)
- Fix: Changed to `useQuery({ ...query, enabled: !isNew })` for conditional detail fetches
- Files modified: `items.$id.tsx`, `modifier-groups.$id.tsx`

**5. [Rule 1 - Bug] Loader `search` param not typed in TanStack Router loader context**

- Found during: Task 3 (`items.tsx`)
- Fix: Simplified loader to prefetch base query without search params; search used in component via `Route.useSearch()`
- Files modified: `items.tsx`

**6. [Rule 1 - Bug] `React.FormEvent` deprecated**

- Found during: Task 2 (`category-form.tsx`)
- Fix: Changed to `React.SyntheticEvent`
- Files modified: `category-form.tsx`

**7. [Rule 1 - Bug] `vi.fn()` mocks referenced before initialization in vitest**

- Found during: Task 4 (spec file)
- Fix: Used `vi.hoisted(() => ({ ... }))` to declare mocks before `vi.mock` factory hoisting
- Files modified: `test/catalog-spa.spec.tsx`
