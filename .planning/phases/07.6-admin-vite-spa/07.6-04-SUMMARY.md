## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] better-auth v1.4.22 missing forgetPassword client method**

- Found during: Task 2 (forgot-password.tsx)
- Issue: TypeScript error — `Property 'forgetPassword' does not exist on type`. The better-auth client at this version only exposes `resetPassword` (token-based), not the request-side method.
- Fix: Used direct `fetch()` to `/api/auth/request-password-reset` with `AbortSignal.timeout(10_000)` and `credentials: 'include'` — matching the path the legacy Next server action called.
- Files modified: `apps/admin/src/routes/(auth)/forgot-password.tsx`
- Commit: 76e6993

**2. [Rule 1 - Bug] TanStack Router location.search is parsed object in beforeLoad**

- Found during: Task 2 (protected \_layout.tsx)
- Issue: TypeScript error `@typescript-eslint/restrict-template-expressions` — `location.search` in a `beforeLoad` context is `Record<string, unknown>`, not a string; template expression `${location.search}` produces `[object Object]`.
- Fix: Dropped search params from the redirect `next` value; safe-next uses `location.pathname` only. Authenticated access to search-param-carrying URLs is a post-login edge case, not a critical redirect target.
- Files modified: `apps/admin/src/routes/(protected)/_layout.tsx`
- Commit: 76e6993

**3. [Rule 1 - Bug] zodResolver type mismatch for optional field with default**

- Found during: Task 2 (signup.tsx)
- Issue: `z.string().optional().default('USD')` — the zod output type is `string` but the input type is `string | undefined`, causing zodResolver type mismatch with react-hook-form.
- Fix: Changed to `z.string().min(1)` (no optional) and added `defaultValues: { defaultCurrency: 'USD' }` to `useForm`.
- Files modified: `apps/admin/src/routes/(auth)/signup.tsx`
- Commit: 76e6993

**4. [Rule 1 - Bug] FormEvent deprecated in React type definitions**

- Found during: Task 3 (onboarding/brand.tsx) — lint-staged caught it pre-commit
- Issue: ESLint error `@typescript-eslint/no-deprecated` on `React.FormEvent`.
- Fix: Changed to `React.SyntheticEvent<HTMLFormElement>`.
- Files modified: `apps/admin/src/routes/(protected)/onboarding/brand.tsx`
- Commit: dc727b3
