# Phase 10.6 Plan 06: Ingredient library, group and dish membership, and composition writes Summary

**Six new `CatalogRepository` methods make D-04 ("exactly once per dish") and D-28 ("removed from those places") queries instead of sentences: `listModifierOptions`/`getModifierOptionUsage`/`archiveModifierOption` for the library screen, `replaceGroupModifierOptions`/`replaceItemModifierOptions` for ordered membership with the cross-set duplicate refusal, and `setItemComposition` for the two-mode composition write — `apps/api:typecheck` is green end to end for the first time since plan 01.**

## Accomplishments

- `listModifierOptions` lists every non-archived ingredient (D-27: no search, no paging), each row carrying a presigned `imageUrl` (never a raw `imageS3Key`), `groupCount` from `menu_modifier_group_options`, and `dishCount` from the union of `menu_item_modifier_options` and composition containment (D-22: group membership alone does not count)
- `getModifierOptionUsage` returns `groups`/`dishesAttached`/`dishesInComposition` as three separately named, deduplicated lists — the archive dialog unions them (D-28), the D-22 stop dialog reads `dishesInComposition` alone
- `archiveModifierOption` sets `archivedAt` (no `DELETE` against `menu_modifier_options` itself) and, in the same tenant-bound transaction, deletes every membership row from both link tables and rewrites `composition_assembled` on every item that referenced it, so an archived ingredient disappears from every place it appeared (D-28)
- `replaceGroupModifierOptions` and `replaceItemModifierOptions` copy `replaceItemModifierGroups`' delete-then-reinsert shape verbatim (verify parent, dedupe, verify every id resolves to a non-archived option, delete filtered on tenant+parent, loop-insert with `sortOrder: index`)
- `replaceItemModifierOptions` runs the D-04 cross-set check before writing: it joins the dish's assigned groups to their option membership, and if an incoming id is already reachable that way it throws `MenuIngredientAlreadyAttachedError(optionId, groupName)` — the group's own name (via the new local `pickLocaleName` helper), not just its id
- `setItemComposition` verifies the item exists and every non-empty `lines[].optionId` resolves to a non-archived ingredient, then writes `compositionMode`/`composition`/`compositionAssembled` in one `updateTable` call — both payloads are always written together so a mode switch can never leave the other stale (D-14/D-15/D-16), and the assembled array's incoming order is preserved with no sort call
- `apps/api:typecheck` exits 0 for the whole app, `test/` included — the red window opened in plan 01 is closed
- `apps/api` catalog unit tests: 49/49; `create-order.service.spec.ts`: 21/21 (plan 04's work undisturbed)
