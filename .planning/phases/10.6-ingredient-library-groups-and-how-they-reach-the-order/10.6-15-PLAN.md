## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator at a location to a stop write | the location is bound server-side; the dialog only chooses which ids to send |
| order payload to the operator's screen | snapshotted names are rendered as text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10.6-15-01 | Tampering | the dish-stop offer stopping a dish the operator did not tick | mitigate | nothing is ticked by default and the spec asserts it; the secondary action sends no dish ids at all |
| T-10.6-15-02 | Information Disclosure | the usage query naming another tenant's dishes in the dialog | mitigate | the read is tenant-bound server-side (plan 06) with RLS behind it |
| T-10.6-15-03 | Tampering | XSS through a snapshotted modifier name on the order sheet | mitigate | rendered as React text content; no `dangerouslySetInnerHTML` is introduced |
| T-10.6-15-04 | Repudiation | an exclusion invisible to the kitchen | mitigate | the exclusion is a structured row rendered as its own line (D-18/D-19), never comment text |
| T-10.6-15-SC | Tampering | npm/pip/cargo installs | mitigate | no package is installed by this plan |
</threat_model>
