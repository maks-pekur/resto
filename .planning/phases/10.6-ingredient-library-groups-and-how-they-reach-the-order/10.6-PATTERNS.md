### `packages/db/src/schema/menu.ts` — two new link tables + ingredient stop table (model, CRUD)

**Analog:** `menuItemModifierGroups` (composite-PK link table, no surrogate id) and `menuStopList` (location-scoped table with two RLS policies)

**Link-table shape to copy verbatim** (`packages/db/src/schema/menu.ts:264-295`):
```typescript
export const menuItemModifierGroups = pgTable(
  'menu_item_modifier_groups',
  {
    tenantId: tenantIdColumn(),
    menuItemId: uuid('menu_item_id').notNull(),
    modifierGroupId: uuid('modifier_group_id').notNull(),
    sortOrder: integer('sort_order').notNull().default(0),
  },
  (table) => [
    primaryKey({
      name: 'menu_item_modifier_groups_pk',
      columns: [table.menuItemId, table.modifierGroupId],
    }),
    foreignKey({
      name: 'menu_item_modifier_groups_tenant_fk',
      columns: [table.tenantId],
      foreignColumns: [tenants.id],
    }).onDelete('cascade'),
    compositeTenantFk({
      name: 'menu_item_modifier_groups_item_fk',
      child: { id: table.menuItemId, tenantId: table.tenantId },
      parent: { id: menuItems.id, tenantId: menuItems.tenantId },
    }).onDelete('cascade'),
    compositeTenantFk({
      name: 'menu_item_modifier_groups_group_fk',
      child: { id: table.modifierGroupId, tenantId: table.tenantId },
      parent: { id: menuModifierGroups.id, tenantId: menuModifierGroups.tenantId },
    }).onDelete('cascade'),
    index('menu_item_modifier_groups_tenant_item_idx').on(table.tenantId, table.menuItemId),
  ],
);
```
`menu_modifier_group_options` (group→ingredient) and `menu_item_modifier_options` (dish→ingredient direct) both copy this shape exactly: `tenantId`, two `uuid().notNull()` parent columns, `sortOrder`, composite PK on the two parent columns (no `id`), tenant FK + two composite FKs, one `tenant_id`-leading index. D-32 requires this literally.

**Location-scoped table with two RLS policies** (`packages/db/src/schema/menu.ts:299-335`, full):
```typescript
export const menuStopList = pgTable(
  'menu_stop_list',
  {
    id: pkUuid(),
    tenantId: tenantIdColumn(),
    locationId: uuid('location_id').notNull(),
    itemId: uuid('item_id').notNull(),
    stoppedAt: timestamp('stopped_at', { withTimezone: true, mode: 'date' }).notNull().default(sql`now()`),
    reason: text('reason'),
    stoppedByUserId: text('stopped_by_user_id'),
  },
  (table) => [
    foreignKey({ name: 'menu_stop_list_tenant_fk', columns: [table.tenantId], foreignColumns: [tenants.id] }).onDelete('cascade'),
    compositeTenantFk({ name: 'menu_stop_list_item_fk', child: { id: table.itemId, tenantId: table.tenantId }, parent: { id: menuItems.id, tenantId: menuItems.tenantId } }).onDelete('cascade'),
    compositeTenantFk({ name: 'menu_stop_list_location_fk', child: { id: table.locationId, tenantId: table.tenantId }, parent: { id: locations.id, tenantId: locations.tenantId } }).onDelete('restrict'),
    uniqueIndex('menu_stop_list_location_item_tenant_uq').on(table.tenantId, table.locationId, table.itemId),
    tenantParentUniqueIndex('menu_stop_list', { id: table.id, tenantId: table.tenantId }),
  ],
);
```
`menu_option_stop_list` copies this exactly, swapping `itemId` for `optionId` (the ingredient FK, pointing at `menuModifierOptions`).

**Helpers to import unchanged** (`packages/db/src/schema/_columns.ts`, full file, 74 lines): `pkUuid()`, `tenantIdColumn()`, `timestampsColumns()`, `tenantParentUniqueIndex()`, `compositeTenantFk()`.

### `packages/db/migrations/0019_<name>.sql` (migration, batch)

**Analog:** `packages/db/migrations/0003_table_zones_and_tables.sql` (full file, 268 lines) — the only recent hand-written multi-table migration and the template RESEARCH §1/§8.1 names explicitly.

Section order to copy (each section's exact SQL shape is in the file at the cited lines):
1. Header comment explaining hand-written status (`0003:1-6`).
2. `CREATE TABLE` + `ALTER TABLE ONLY ... FORCE ROW LEVEL SECURITY` per table (`0003:8-44`).
3. `CREATE UNIQUE INDEX ..._id_tenant_uq` **before** the FKs that reference it — Postgres requires the unique index to exist first (`0003:47-66`).
4. `ALTER TABLE ONLY ... ADD CONSTRAINT ... FOREIGN KEY (child_id, tenant_id) REFERENCES parent(id, tenant_id)` (`0003:68-86`).
5. RLS: `ENABLE ROW LEVEL SECURITY` + `CREATE POLICY ..._iso` (PERMISSIVE, tenant-only) for the two link tables; add the second `CREATE POLICY ..._location_iso AS RESTRICTIVE` for `menu_option_stop_list` (`0003:97-107`, copied from `menu_stop_list_iso`/`menu_stop_list_location_iso` pattern cited at `0000_baseline.sql:1175-1179`).
6. Sibling-table `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` for `order_modifiers.kind` (mirrors `0003:116-124`'s `orders` column additions — same `ADD COLUMN IF NOT EXISTS` idiom, own FK/constraint section if needed).
7. `resto_app` grants in a guarded `DO $$ ... IF EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'resto_app') ... $$` block (`0003:126-135`) — **plus explicit `GRANT DELETE`** for `menu_modifier_group_options`/`menu_item_modifier_options`/`menu_option_stop_list` (delete-then-reinsert / unstop patterns), following the `menu_item_modifier_groups`/`menu_stop_list` precedent in `roles.sql:67-86` — restate the grant in both the migration and `roles.sql`.

  return this.db.withTenant(async (tx, scoped) => {
    const itemRows = await scoped.selectFrom(schema.menuItems, eq(schema.menuItems.id, input.itemId)).limit(1);
    if (!itemRows[0]) throw new MenuItemNotFoundError(input.itemId);

    const dedupedIds = [...new Set(input.modifierGroupIds)];
    if (dedupedIds.length > 0) {
      const foundGroups = await scoped.selectFrom(schema.menuModifierGroups, inArray(schema.menuModifierGroups.id, dedupedIds));
      const foundSet = new Set(foundGroups.map((g) => g.id));
      const firstMissing = dedupedIds.find((id) => !foundSet.has(id));
      if (firstMissing !== undefined) throw new MenuModifierGroupNotFoundError(firstMissing);

    return { id: input.itemId };

}
