<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator browser to the presign endpoint and then to S3 | the upload is a direct browser PUT against a URL the server signed |
| admin route to the API | route visibility is convenience; the API's `@Permissions` is the refusal |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10.6-12-01 | Tampering | the client naming its own S3 path | mitigate | `PhotoUpload` sends only a `kind` discriminator; the whole key including the tenant segment is built server-side (plan 07) |
| T-10.6-12-02 | Elevation of Privilege | a read-only operator reaching the editor | mitigate | the sidebar gate hides the section and every write route refuses server-side; hiding a control is convenience, per the admin-ui skill |
| T-10.6-12-03 | Repudiation | archiving an in-use ingredient without the operator understanding the blast radius | mitigate | the confirmation names every group and dish before the write (D-28) |
| T-10.6-12-04 | Denial of Service | an over-long description reaching the API | mitigate | `.max(140)` client-side and server-side |
| T-10.6-12-SC | Tampering | npm/pip/cargo installs | mitigate | no package is installed by this plan |
</threat_model>
