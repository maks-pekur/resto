<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator browser to the presign endpoint | the client asks for an upload URL and gets back a key it will later store; it must not be able to influence the path |
| operator at location A to location B's stop rows | stop writes are location-scoped and the location comes from the bound context, not the body |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10.6-07-01 | Tampering | cross-tenant photo overwrite via a presigned PUT | mitigate | the key is `tenant/{ctx.tenantId}/{prefix}/{randomUUID}.{ext}` where the tenant segment comes from the bound context and the prefix from a validated two-value enum — no request string reaches the path |
| T-10.6-07-02 | Denial of Service | a long-lived presign token | accept | the existing 300s TTL ceiling is unchanged (OWASP V12, already enforced) |
| T-10.6-07-03 | Tampering | stopping an ingredient at another location | mitigate | the stop write goes through `db.withTenant` + the RESTRICTIVE location policy from plan 02; the location is taken from the bound context exactly as the item stop already does |
| T-10.6-07-04 | Denial of Service | a stop write that silently invalidates every tenant's menu cache | accept | the bump is per location on the existing counter, unchanged semantics from item stops |
| T-10.6-07-SC | Tampering | npm/pip/cargo installs | mitigate | no package is installed by this plan |
</threat_model>
