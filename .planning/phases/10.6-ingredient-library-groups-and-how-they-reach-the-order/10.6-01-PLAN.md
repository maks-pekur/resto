<objective>
Reshape the Drizzle schema so an ingredient is a tenant-level entity, membership lives in link
tables, a group is described by two enums, a dish carries a two-mode composition, and an
`order_modifiers` row can say `excluded`.

Purpose: every other plan in this phase reads its types from these table definitions. Nothing
downstream compiles until this lands.
Output: reshaped `packages/db/src/schema/menu.ts` + `ordering.ts`, a rewritten domain modifier
schema. No SQL yet — plan 02 writes the migration that makes the database agree.
</objective>
