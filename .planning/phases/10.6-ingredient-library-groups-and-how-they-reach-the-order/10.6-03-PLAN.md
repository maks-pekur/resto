<objective>
Rebuild the published-menu read model so an ingredient travels once, a group says how it is
rendered and how many may be chosen, a dish carries its composition, and a stopped ingredient
reaches the guest through the availability endpoint.

Purpose: this is the wire contract three later plans implement against — ordering (plan 04), the
guest apps (plan 08) and the admin (plan 10). It is the widest single change in the phase.
Output: a `/v1/menu` payload with a top-level `modifierOptions[]` and a `/v1/menu/availability`
response with two lists.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet to `/v1/menu` and `/v1/menu/availability` | unauthenticated reads; the response must never carry an S3 key, another tenant's row, or an unbounded string |
| Postgres row to wire | `image_s3_key` is an internal key; only a presigned URL may cross |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10.6-03-01 | Information Disclosure | `menu_modifier_options.image_s3_key` on the public payload | mitigate | the repository emits `imageUrl` via `this.imageUrl.publicUrl(key)`; the raw key is never placed on `PublishedMenuModifierOption` and the wire schema has no `s3Key` field |
| T-10.6-03-02 | Information Disclosure | cross-tenant options leaking into a menu | mitigate | every read goes through `scoped.selectFrom` inside `db.withTenant` (ADR-0020 I-1) plus the RLS from plan 02; no raw `tx.select` is introduced |
| T-10.6-03-03 | Denial of Service | unbounded `composition` / `compositionLines` arrays on a public response | mitigate | `.max(50)` on both arrays and `.max(100)` per free-text entry in the wire schema |
| T-10.6-03-04 | Information Disclosure | stop state revealing operational data | accept | a stopped ingredient is guest-visible by design (D-21) and reveals no more than a stopped item does today |
| T-10.6-03-SC | Tampering | npm/pip/cargo installs | mitigate | no package is installed by this plan |
</threat_model>
