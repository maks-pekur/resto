<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server payload to guest render | the menu is untrusted-ish input to the browser: ids may not resolve, arrays may be empty |
| guest cart to `POST /v1/orders` | everything built here is re-validated server-side; the client is a convenience, never an authority |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10.6-09-01 | Tampering | a guest editing local state to send a free or forged modifier | mitigate | plan 04 re-prices from the published snapshot and re-checks the union set and `removableOptionIds`; nothing in this plan is trusted server-side |
| T-10.6-09-02 | Denial of Service | an `optionId` in a group or composition that is absent from `modifierOptions` crashing the sheet | mitigate | the lookup is a Map and every read is guarded — an unresolved id renders nothing rather than throwing |
| T-10.6-09-03 | Information Disclosure | wire-type drift silently widening a field to `any` and leaking a raw S3 key into the DOM | mitigate | the three files are changed together and each field is checked against `public-menu.controller.ts`; the payload has no key field to leak |
| T-10.6-09-SC | Tampering | npm/pip/cargo installs | mitigate | no package is installed by this plan |
</threat_model>
