<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server payload to guest DOM | localized text and presigned URLs are rendered; neither may be interpolated as HTML |
| guest tap to cart line | exclusion state is local and advisory; the server re-validates every row (plan 04) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10.6-10-01 | Tampering | XSS through an ingredient name or description | mitigate | every string is rendered as React text content; no `dangerouslySetInnerHTML` is introduced anywhere in the two new components |
| T-10.6-10-02 | Information Disclosure | a presigned `imageUrl` rendered where it can be scraped | accept | the same exposure item photos already have; the URL is short-lived and the bucket is private |
| T-10.6-10-03 | Tampering | selecting a stopped ingredient from a disabled control | mitigate | the input is `disabled` here AND the order is refused server-side by plan 04 — the client control is convenience, the server is the authority |
| T-10.6-10-04 | Denial of Service | an unresolved option id in `optionIds` or `compositionLines` crashing the sheet | mitigate | every lookup is guarded and an unresolved id renders nothing |
| T-10.6-10-SC | Tampering | npm/pip/cargo installs | mitigate | no package is installed by this plan; `radio-group` in plan 11 is a shadcn CLI copy into `apps/admin`, not an npm dependency. The guest bundle grows by exactly one lucide export (`NoPhotoIcon`) through the existing allowlist |
</threat_model>
