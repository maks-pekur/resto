<objective>
Build the server-managed, non-forgeable active-location session pin and the location scope reader. This is the phase's core session/isolation novelty: the pin is asymmetric — owners re-pin silently (D-09), staff are pinned once at session creation and must re-login to switch (D-10/D-11) — and reachable brands are now DERIVED from ACTIVE scoped locations (D-04). It also reconciles the existing brand-switch path so `activeLocationId` never dangles onto a location of a different brand (D-08).

Purpose: Provide the session state and scope-resolution primitives that LocationScopeGuard (plan 05), LocationPermissionChecker (plan 07), and the admin surfaces (plans 09/10) all consume — with the archived-location filter that makes D-17 access-loss real.
Output: `activeLocationId` session field, `SetActiveLocationService` (asymmetric), `SetActiveBrandService` reconciliation, `GET /v1/me/locations`, the active-status-filtered `member_location_scope` reader, initial-pin wiring, and request-time surfacing/binding.
</objective>
