Build the server-managed, non-forgeable active-location session pin and the location scope reader. | ---------------------------------- | ---------------------------------------------------------------------------------- |
| client -> session activeLocationId | Client must never set the pin; only server code writes via internalAdapter.        |
| client -> x-location-id header     | Header is a hint echoed from session; the guard (plan 05) is the real cross-check. |

## STRIDE Threat Register

| Threat ID | Category               | Component                                                                   | Disposition | Mitigation Plan                                                                                                                                    |
| --------- | ---------------------- | --------------------------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-084-06  | Elevation of Privilege | non-owner self-re-pins to another location without re-login (bypasses D-11) | mitigate    | Asymmetric write: non-owner may only transition null->value once; server rejects overwrite of a non-null value (Task 3, unit-proven).              |
| T-084-07  | Spoofing               | client forges activeLocationId in the sign-in/update body                   | mitigate    | `input: false` on the additionalField blocks any client-supplied value; only `internalAdapter.updateSession` writes it.                            |
| T-084-08  | Information Disclosure | reachable-brand derivation leaks a brand the member has no location in      | mitigate    | `findReachableBrandsForMember` joins strictly through member_location_scope -> locations; a zero-location brand yields zero rows (D-04 invariant). |
| T-084-09  | Spoofing               | forged x-location-id points at an out-of-scope location                     | transfer    | Middleware only binds the ALS value; LocationScopeGuard (plan 05) cross-checks header vs session -> existence-hiding 404.                          |
| T-084-27  | Information Disclosure | GET /v1/me/locations lists locations a non-owner cannot pin                 | mitigate    | Non-owner branch of findPinnableLocations returns only scoped active locations of the active brand; owner scoped to the active brand only.         |
