# Phase 07.5 Plan 13: Collapse to One Apex Summary

**`GUEST_APEX_DOMAIN` deleted everywhere in `apps/api`; one `guest-links.ts` module now composes every guest-facing URL — the QR sticker carries `/qr/t/<token>`, both tenancy writers stop hardcoding `menu.resto.app`, and the guest confirmation email links to the tenant's own host instead of the bare apex.**

## Performance

- **Completed:** 2026-09-06T00:25:00Z
- **Tasks:** 2/2
- **Files modified:** 19 (3 created, 15 modified, 1 deleted/renamed into `todos/done/`)

## Accomplishments

- `apps/api/src/shared/guest-links.ts` — three exports (`guestHostForTenant`, `guestMenuStickerUrl`, `guestOrderStatusUrl`) plus the two path constants (`GUEST_MENU_BASE_PATH = '/qr'`, `GUEST_ORDER_STATUS_PATH = '/checkout/confirmation'`), mirroring `admin-links.ts`'s shape and confinement.
- `GUEST_APEX_DOMAIN` deleted from `env.schema.ts` (declaration + refinement), `prod-guardrails.ts` (the now-redundant ephemeral-host check — confirmed by reading that `PUBLIC_APEX_DOMAIN`'s own check at the line above already covers the same protection), and `tenant-resolver.service.ts`'s `guestSlugLabel` (the three-line branch plus both doc comments describing the two-apex world).
- `GuestMenuUrlService.execute` now composes through `guest-links.ts`; the sticker URL carries `/qr/t/<token>` on both the apex branch and the custom-domain branch.
- `provision-tenant.service.ts` and `finalize-tenant-onboarding.service.ts` inject `Env`, delete `PRIMARY_DOMAIN_SUFFIX = 'menu.resto.app'`, and compose the primary domain through `guestHostForTenant(env, tenant, null)` — throwing, naming the slug, when `PUBLIC_APEX_DOMAIN` is unset.
- `send-guest-notification.service.ts`'s confirmation link is now per-tenant: `NotificationOrderDrizzleRepository.findOrder`'s projection grew `tenantSlug` and `primaryCustomDomain` (a new `LEFT JOIN` on `tenant_domains`), and the service composes `guestOrderStatusUrl` from them, falling back to the old relative path only when neither an apex nor a custom domain is configured.
- The `tenant-primary-domain-ignores-configured-apex` todo closed into `.planning/todos/done/`.
