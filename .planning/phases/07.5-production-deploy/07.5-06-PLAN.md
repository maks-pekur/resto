## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → RDS | RDS is in a private subnet with NO public access; its security group admits only the ECS task SG |
| admin role → schema | migrations + role provisioning use the privileged admin/rds_superuser string; never the runtime app |
| resto_app → tenant data | NOBYPASSRLS + FORCE RLS is the isolation fence |
| resto_auth → BA-owned tables | resto_auth (NOBYPASSRLS) reaches its BA-owned RLS tables via migration-0054 permissive policies; reaches non-RLS BA credential tables as a plain grantee; scope strictly limited to BA-owned tables (auth-role.sql) |
| snapshot → restored instance | restored copy contains real (eventually PII) data; torn down after the drill |
