<objective>
Stand up the hosting surface: ECS Express Mode services for api + admin behind an ALB with an ACM
wildcard cert, Cloudflare in front (DNS + Full-strict TLS + CDN cache rules), and AWS Secrets
Manager injecting every runtime secret at task launch. This is the bulk of success criterion 1
(api + admin run in managed prod over HTTPS on a real domain) and criterion 2 (runtime secret
injection, never baked into images).

Per RESEARCH: AWS Copilot is EOL (June 2026) — use ECS Express Mode (it provisions VPC, ALB,
Fargate, CloudWatch logs, IAM in one shot, satisfying D-03 "minimal IaC, no sprawling Terraform").
The api service MUST keep >=1 always-on task (D-02) or the outbox leader never runs. TRUST_PROXY
must be a hop count/CIDR (env.schema rejects 'true' in non-dev). Secrets go through Secrets Manager
(D-09); assertProdGuardrails already fails-closed on placeholder secrets, so real values must be
injected.

Purpose: This is the public-HTTPS plumbing the whole phase exists to deliver, kept deliberately
boring/managed (Express Mode, no k8s, no multi-region — investor anti-gold-plating BLOCK).
Output: live api + admin over HTTPS, Cloudflare CDN on the menu reads, secrets injected at runtime,
and two runbooks.
</objective>

## Trust Boundaries

| Boundary                                        | Description                                                              |
| ----------------------------------------------- | ------------------------------------------------------------------------ |
| public internet -> Cloudflare -> ALB -> Fargate | The public HTTPS ingress; the primary attack surface this phase opens    |
| Secrets Manager -> ECS task env                 | Secret material delivered at launch; must be ARN-scoped to the task role |
| Cloudflare -> ALB origin                        | Origin-trust boundary; Flexible SSL would downgrade to HTTP              |
| client Host header -> TenantContextMiddleware   | Tenant resolution from a forwarded, spoofable header                     |

## STRIDE Threat Register

| Threat ID | Category               | Component                              | Disposition | Mitigation Plan                                                                                                                             |
| --------- | ---------------------- | -------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| T-075-19  | Information Disclosure | secrets baked into image/env           | mitigate    | Secrets Manager injection via task execution role scoped to specific ARNs; nothing in the image (assertProdGuardrails rejects placeholders) |
| T-075-20  | Spoofing (origin)      | Cloudflare SSL Flexible -> HTTP to ALB | mitigate    | SSL Full (strict); ALB HTTPS listener with ACM cert; no HTTP origin                                                                         |
| T-075-21  | Spoofing (IP/Host)     | TRUST_PROXY=true / Host spoofing       | mitigate    | TRUST_PROXY='1' (one hop) or ALB CIDR; env.schema rejects 'true' in non-dev; tenant existence-hiding 404 already shipped                    |
| T-075-22  | Elevation of Privilege | over-broad task execution IAM          | mitigate    | Task role granted read only on the specific secret ARNs; ECS Express Mode least-privilege defaults                                          |
| T-075-23  | Denial of Service      | api scaled to zero -> no outbox leader | mitigate    | api service min tasks >= 1 (D-02); outbox_leader readiness (07.5-03) replaces a wedged task                                                 |
