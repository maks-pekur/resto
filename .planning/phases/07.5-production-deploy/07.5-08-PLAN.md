<objective>
Stand up the FULL customer-facing hosting surface: ECS Express Mode services for api + admin +
website behind an ALB with an ACM wildcard cert, the qr-menu Vite SPA on Cloudflare static hosting,
Cloudflare in front (DNS + Full-strict TLS + CDN cache rules + the *.menu.resto.app static + /v1
routing), and AWS Secrets Manager injecting every runtime secret at task launch. This is the bulk
of success criterion 1 (api + admin + website + qr-menu run in managed prod over HTTPS on real
domains) and criterion 2 (runtime secret injection, never baked into images). The website is the
public ordering shopfront — checkout stays disabled until Phase 8, but the surface goes live now.

Per RESEARCH: AWS Copilot is EOL (June 2026) — use ECS Express Mode (it provisions VPC, ALB,
Fargate, CloudWatch logs, IAM in one shot, satisfying D-03 "minimal IaC, no sprawling Terraform").
The api service MUST keep >=1 always-on task (D-02) or the outbox leader never runs. admin + website
are additional Next SSR Fargate services (their Dockerfiles come from 07.5-11). qr-menu is a static
Vite SPA — NOT an ECS service — deployed to Cloudflare Pages or R2+CDN; it fetches /v1/menu
same-origin, so Cloudflare must route /v1/* on *.menu.resto.app to the ALB origin and serve the
static bundle for everything else (RESEARCH Pitfall 10). TRUST_PROXY must be a hop count/CIDR
(env.schema rejects 'true' in non-dev). Secrets go through Secrets Manager (D-09);
assertProdGuardrails already fails-closed on placeholder secrets, so real values must be injected.

Purpose: This is the public-HTTPS plumbing the whole phase exists to deliver, now covering the full
customer surface (the website shopfront + the QR menu), kept deliberately boring/managed (Express
Mode + managed static hosting, no k8s, no multi-region — investor anti-gold-plating BLOCK).
Output: live api + admin + website over HTTPS, qr-menu static on *.menu.resto.app, Cloudflare CDN on
the menu reads, secrets injected at runtime, and two runbooks.
</objective>

## Trust Boundaries

| Boundary                                        | Description                                                              |
| ----------------------------------------------- | ------------------------------------------------------------------------ |
| public internet -> Cloudflare -> ALB -> Fargate | The public HTTPS ingress; the primary attack surface this phase opens    |
| public internet -> Cloudflare static (qr-menu)  | The static SPA surface; /v1 must route to the ALB origin, the rest static |

| client Host header -> TenantContextMiddleware   | Tenant resolution from a forwarded, spoofable header                     |
