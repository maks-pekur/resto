<objective>
G-01 BLOCK gate: Fix the known `import.meta.dirname`-in-CJS Docker boot bug and PROVE it
fixed with a green production container that passes all 8 boot preflights against real
managed Postgres, then restore the CI docker-api job that was deliberately deleted so the bug
can never silently reach a public URL again.

Root cause (RESEARCH §G-01, verified from code): esbuild rewrites `import.meta.dirname` ->
`__dirname` in the CJS bundle; in `dist/main.cjs` that is `/app/apps/api/dist/`, so
`resolve(import.meta.dirname,'..','sql','roles.sql')` -> `/app/apps/api/sql/roles.sql`, which
does not exist (the real file is at `/app/packages/db/sql/roles.sql`). `readFileSync` throws
before any preflight runs — a public URL would ship a binary that crashes on boot.

Purpose: This is success criterion 4 ("boot preflights pass in real prod; the process refuses
to start on misconfiguration") and the CTO/Investor's top operational BLOCK. The whole phase
is gated on this being green.
Output: Inlined SQL via esbuild text loader; a restored CI gate; a verified-bootable image.
</objective>
