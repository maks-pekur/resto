<objective>
Build the backend `all` aggregate that resolves the documented 08.4 gap (c): an owner in brand-global mode currently 403s (`location.context_required`) on the location-grain stop-list. Deliver `GET /v1/catalog/stop-list/aggregate` — `@LocationNeutral()` (so it bypasses `LocationScopeGuard`'s context-required check, the actual gap fix per D-08) and `@OwnerOnly()` (the plan-01 gate, because a `@LocationNeutral` endpoint is otherwise reachable by any brand member — BLOCK-1). The aggregate is a single set-based `GROUP BY` over the brand's server-resolved ACTIVE locations, tenant-bound, paginated, off the edge cache.

Also close D-10's single-location half: the owner single-location stop-list read must validate the resolved `x-location-id` belongs to the active brand and is not archived (existence-hiding 404), because owners bypass `LocationScopeGuard` and nothing else validates it today.

Record the D-11 decision explicitly: `LocationPermissionChecker` is RE-DEFERRED (not wired). Wiring it requires `PermissionsGuard` to thread `activeLocationId`, and a blind swap would block all non-owner permission checks (STATE gap b). All location confinement in this phase = `LocationScopeGuard` + `OwnerOnlyGuard`.

Purpose: give the client an owner-only, edge-cache-free, O(1) aggregate to render `all` mode without white-screens.
Output: aggregate row type + DTO, repository GROUP BY method, aggregate service, controller endpoint, D-10 single-location validation, and e2e proving BLOCK-1 + D-10.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> GET /v1/catalog/stop-list/aggregate | A `@LocationNeutral` endpoint bypasses LocationScopeGuard; any authenticated brand member could otherwise reach cross-location data. This is the load-bearing boundary of the phase. |
| client -> GET /v1/catalog/stop-list (x-location-id) | An owner bypasses LocationScopeGuard; a forged/foreign/archived `x-location-id` must not read out-of-brand data. |
| aggregate query -> DB | The location set must be server-derived, never accepted from the caller. |
