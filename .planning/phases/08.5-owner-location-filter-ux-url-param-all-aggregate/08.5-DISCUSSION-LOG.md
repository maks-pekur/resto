## Вид «all» у владельца

| Option               | Description                                                                                          | Selected |
| -------------------- | ---------------------------------------------------------------------------------------------------- | -------- |
| Только итоги         | Счётчики = одно объединённое число; стоп-лист = позиции снятые где-либо, с пометкой «снято в N из M» | ✓        |
| Разбивка по локациям | Карточка/строка на каждую локацию с её числами и стоп-листом                                         |          |
| Итог + разворот      | Объединённый итог сверху + разворачиваемая разбивка (гибрид)                                         |          |

**User's choice:** Только итоги (merged totals; N/M badge on stop-list).
**Follow-up — действия в `all`:**

| Option                     | Description                                                                   | Selected |
| -------------------------- | ----------------------------------------------------------------------------- | -------- |
| all — только обзор         | Стоп-лист read-only в `all`; снять/вернуть — только выбрав конкретную локацию | ✓        |
| Действие с выбором локаций | Из `all` можно снять, с выбором в каких локациях (bulk)                       |          |

**Notes:** Read-only in `all` avoids ambiguous "stop everywhere?" semantics; write endpoints stay location-scoped. → CONTEXT D-05, D-06.

## Edge cases

### Ноль локаций у владельца

| Option               | Description                                                                               | Selected |
| -------------------- | ----------------------------------------------------------------------------------------- | -------- |
| Пустое + CTA создать | Empty state + "create location" CTA (owner has Locations CRUD from 08.4); switcher hidden | ✓        |
| all с нулями         | Show `all` aggregate with zeros + a hint                                                  |          |

**Choice:** Пустое + CTA создать. → CONTEXT D-19.

### Невалидный / чужой / архивный ?location

| Option                | Description                                                            | Selected |
| --------------------- | ---------------------------------------------------------------------- | -------- |
| Тихий откат на дефолт | Client falls back to first location; non-owner still 403/404 via guard | ✓        |
| Ошибка / 404          | Show not-found                                                         |          |

**Choice:** Тихий откат на дефолт (CLIENT-ONLY per persona MED-10 — server still 403/404s out-of-scope; also add server-side owner location∈brand validation per HIGH-2). → CONTEXT D-10, D-18.

| Option         | Description                                               | Selected |

**Choice:** По алфавиту. **Persona FLAG (MED-9):** mutable home view — recommended stable key. Kept as chosen; flagged in CONTEXT D-03.
