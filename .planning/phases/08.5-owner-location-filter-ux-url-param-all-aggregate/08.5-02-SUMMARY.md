## Decisions Made

- Owner branch retirement is a no-op return, not an endpoint removal — keeps `SetActiveLocationInput`/`SetActiveLocationResult` shapes stable per plan's acceptance criteria (no signature restructuring).
- D-14's non-owner branch was deleted outright (not converted to an unreachable dead branch behind a flag) so the reachable-brands scope-mutation surface is structurally gone, matching the persona-review rationale ("shrinking a reachable scope-mutation endpoint is a security win").
- `location-isolation.e2e.spec.ts`'s `beforeAll` fixture no longer calls `setActiveBrand` for the staff persona — traced that the sign-in flow's existing `onInitialBrandPin`/`onInitialLocationPin` Better Auth hooks (auth.config.ts) already auto-pin the single reachable brand/location from `member_location_scope` at login, making the explicit call both redundant and (post-D-14) forbidden.
- LOW-11 left unfixed by design per the plan's own threat-register disposition (`accept`, T-085-08) — adding session invalidation to `afterUpdateMemberRole` was assessed as higher-risk than the current fail-closed behavior.
