<objective>
Rebuild the ordering domain layer on top of plan 10-01's columns: extend the domain events and their v1 wire contracts (D-05), widen and correct the state machine (D-08, D-09, D-10), and teach the repository to persist and read every new column while fixing the hardcoded event payload values.

Purpose: this is the layer every operator action in the phase runs through, and it currently contains two live correctness bugs — `refund()` overwrites the order's fulfillment status from refund completeness, and `cancel()` is illegal from `accepted` onward. Both must be fixed before any service or controller is built on top.

Output: a state machine whose only terminal-status writer is `cancel()`, events that carry `locationId`/actor/real money, and a repository that round-trips every new column.
</objective>
