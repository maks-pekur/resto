## Critical Anti-Patterns

| Pattern                                 | Description                                                                                                                                                                                                               | Severity | Prevention                                                                                         |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | -------------------------------------------------------------------------------------------------- |
| api e2e batched in one process          | Running two or more `apps/api` e2e specs in a single vitest process produces failures that vanish when the spec runs alone. Hit twice this session (`catalog-tenant-read-isolation`, and a false read of the unit count). | advisory | One spec per process. The audit loop below already does this.                                      |
| stale `node_modules` across branches    | `better-auth` is 1.6.30 on one branch and 1.4.22 on the others. Switching branches without `pnpm install` typechecks the new source against the old types and invents errors.                                             | advisory | `pnpm install` after every checkout between these branches.                                        |
| commitlint rejects merge commits        | `git merge -m "Merge X"` fails the husky `commit-msg` hook.                                                                                                                                                               | advisory | Give merges a conventional subject: `chore: merge …`.                                              |
| verification that stops at static gates | PR #261 made coordinates required and broke 11 call sites across eight e2e suites. Typecheck, lint and unit tests were all green.                                                                                         | blocking | When a request/response contract changes, grep for every caller in `test/` before calling it done. |
